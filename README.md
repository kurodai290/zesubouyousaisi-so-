# シーソーゲーム（試作品）

## 遊び方
1. `index.html` をブラウザで開きます。
2. 「ゲームスタート」を押します。
3. 左右の矢印キーで足場を傾け、白いボールを `GOAL` へ運びます。
4. ライフがなくなるか、制限時間が0になると失敗です。

## ファイル
- `index.html`：ゲーム画面
- `style.css`：見た目
- `game.js`：ゲームの動き・ステージ・判定

## GitHub Pagesで使う場合
3つのファイルを同じフォルダにアップロードしてください。フォルダ構成は変えず、`index.html` を開きます。

## 注意
これは、動画と説明をもとにした試作品です。STAGE 1〜3は聞いた仕様を反映し、STAGE 4〜8は動画から着想した仮の仕掛けです。元ゲームの完全な再現ではありません。
